# Contributing

Contributions should strengthen the practical GRC workflow focus of this project.

## Contribution Guidelines

- Keep skills practical and workflow-based.
- Do not add confidential company information.
- Use fictional or sanitized examples.
- Keep instructions clear and repeatable.
- Avoid turning this project into a generic framework encyclopedia.
- Include examples when adding a new skill.

## Skill Naming

Use lowercase hyphenated names, such as:

```text
change-governance-review
```

## Review Standard

A skill should help a practitioner produce an output that could be used in a real governance workflow.
