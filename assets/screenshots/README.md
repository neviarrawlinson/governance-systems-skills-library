# Screenshot Assets

Store project screenshots in this folder.

Recommended filenames:

```text
landing-page-hero.png
skill-packs-section.png
tested-output-index.png
github-repo-structure.png
skills-folder.png
tested-output-example.png
actions-validation-success.png
release-assets.png
```

## Recommended Screenshot Set

| Screenshot | Purpose |
|---|---|
| `landing-page-hero.png` | Shows the live GitHub Pages landing page and project branding. |
| `skill-packs-section.png` | Shows the skill library scope and available GRC skills. |
| `tested-output-index.png` | Shows proof that tested examples exist for all skills. |
| `github-repo-structure.png` | Shows the repo is organized and portfolio-ready. |
| `skills-folder.png` | Shows the Claude-compatible skill folders. |
| `tested-output-example.png` | Shows a realistic tested governance output. |
| `actions-validation-success.png` | Shows automated validation passed. |
| `release-assets.png` | Shows packaged skill downloads are available. |
