# prepare-cab-summary

Prepare a CAB-ready summary for one or more change requests.

## Use when

Use this command when the user needs a CAB agenda, CAB review note, CAB decision summary, or leadership-ready change review summary.

## Related skills

Use `cab-readiness-check`, `change-governance-review`, and `executive-grc-summary`.

## Output format

### CAB Summary

| Ticket | System | Environment | Risk | Recommendation | Conditions |
|---|---|---|---|---|---|

### Changes Ready for CAB Decision

List changes that are ready or ready with conditions.

### Changes Not Ready

List changes that should be held, rejected, or returned to the requester.

### Governance Notes

Provide concise notes for the CAB chair or governance owner.

### Follow-Up Actions

List owners, due dates, and required closure actions if available.
