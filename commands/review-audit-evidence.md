# review-audit-evidence

Review an audit evidence package for completeness, traceability, date coverage, reviewer signoff, control relevance, and submission readiness.

## Related skills

Use `audit-evidence-request` and `control-evidence-quality-check`.

## Output format

### Audit Evidence Review

Status: Ready / Ready with Explanation / Not Ready  
Evidence Risk: Low / Medium / High  
Submission Recommendation: Submit / Hold / Submit with Exception Note

### Evidence Checklist

| Evidence Item | Status | Required Action |
|---|---|---|

### Likely Auditor Concerns

List likely auditor questions or concerns.

### Submission Note

Draft a concise submission note or exception note.

### Next Action

Provide one clear next action.
