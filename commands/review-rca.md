# review-rca

Review an RCA for governance quality, root cause completeness, monitoring failure analysis, ownership, corrective actions, and audit readiness.

## Use when

Use this command when the user provides an incident report, RCA, postmortem, outage summary, corrective action plan, or production failure summary.

## Related skill

Use the `rca-governance-analysis` skill.

## Output format

### RCA Governance Review

Status: Ready / Needs Revision / Not Ready  
Governance Risk: Low / Medium / High  
Leadership Readiness: Ready / Not Ready  
Audit Readiness: Ready / Not Ready

### Key Findings

- Finding 1
- Finding 2
- Finding 3

### RCA Gaps

| RCA Area | Gap | Required Fix |
|---|---|---|

### Corrective Action Review

Assess whether actions have named owners, due dates, evidence requirements, and closure criteria.

### Governance Note

Provide a concise governance note suitable for a Jira or Confluence RCA record.
