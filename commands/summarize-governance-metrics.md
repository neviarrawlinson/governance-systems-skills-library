# summarize-governance-metrics

Turn governance metrics into a leadership-ready summary with current status, trends, risks, exceptions, insights, and recommended actions.

## Related skill

Use the `governance-metrics-summary` skill. If needed, use `executive-grc-summary` to create a shorter leadership version.

## Output format

### Executive Governance Metrics Summary

Status: On Track / At Risk / Needs Attention  
Primary Risk Theme:  
Leadership Decision Needed:

### Key Metrics

| Metric | Count | Interpretation |
|---|---:|---|

### Trends and Insights

List the most important patterns.

### Exceptions

List issues needing leadership visibility.

### Recommended Actions

List specific actions, owners, and timing if available.
