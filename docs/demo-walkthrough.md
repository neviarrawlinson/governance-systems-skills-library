# Demo Walkthrough

This walkthrough explains how to demonstrate the Governance Systems Skills Library in a clear, practical way for recruiters, hiring managers, GRC leaders, auditors, and technical stakeholders.

## Demo Goal

Show that the project is more than a prompt library. It is a structured Governance Systems Engineering project that turns GRC expectations into repeatable workflows, tested outputs, framework mappings, and audit-ready records.

## Recommended Demo Flow

### 1. Start With the Problem

Governance often fails because policies and standards are documented, but the actual control expectations are not embedded into daily workflows such as change tickets, CAB reviews, RCAs, evidence packages, risk registers, vendor intake, and AI intake.

### 2. Show the Live Site

Open the GitHub Pages site:

https://neviarrawlinson.github.io/governance-systems-skills-library/

Point out the Governance Systems Engineering positioning, skill library overview, tested outputs, framework mapping, and installation resources.

### 3. Show the GitHub Repository

Open the repo:

https://github.com/neviarrawlinson/governance-systems-skills-library

Highlight `skills/`, `examples/`, `framework-mapping/`, `docs/`, `templates/`, `.github/workflows/`, and `dist/`.

### 4. Open a Skill

Recommended skill to demo first:

`skills/change-governance-review/SKILL.md`

Explain that each skill contains reusable instructions that guide AI-assisted governance review.

### 5. Show a Tested Output

Open:

`skills/change-governance-review/examples/tested-output.md`

Explain that the skill was tested against a realistic production change scenario and produced a structured governance review.

### 6. Show the End-to-End Demo

Open:

`examples/end-to-end-change-governance-demo.md`

Explain how one operational event can flow through change review, CAB readiness, RCA governance, audit evidence review, risk register entry, and executive summary.

### 7. Show Framework Mapping

Open:

`framework-mapping/skill-to-framework-matrix.md`

Explain that the library maps practical workflows to recognized governance frameworks such as ISO 27001, SOC 2, NIST CSF, COBIT, and AI governance themes.

### 8. Show Automation

Open the Actions tab and point out the Validate Skills and Package Skills workflows.

Explain that the project uses GitHub Actions to validate the skill structure and generate downloadable packages.

### 9. Close With the Value

Use this closing statement:

This project demonstrates how GRC can be operationalized as a system of repeatable workflows, structured evidence requirements, decision points, risk handling, and leadership-ready outputs.
