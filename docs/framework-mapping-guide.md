# Framework Mapping Guide

This guide explains how to use the framework mapping folder in the Governance Systems Skills Library.

## Purpose

The framework mapping documents help connect the skill library to recognized GRC concepts and control themes. The project is workflow-centered, but the workflows support broader governance and audit-readiness objectives.

The mapping files are useful for:

- Portfolio storytelling.
- Interview discussion.
- GRC training.
- Audit-readiness planning.
- Governance program design.
- Explaining how skills connect to control objectives.

## Included Mapping Files

| File | Purpose |
|---|---|
| `framework-mapping/skill-to-framework-matrix.md` | High-level matrix showing how each skill connects to major governance frameworks. |
| `framework-mapping/iso-27001-skill-mapping.md` | ISO 27001-aligned governance themes for each skill. |
| `framework-mapping/soc-2-skill-mapping.md` | SOC 2-relevant evidence and control themes for each skill. |
| `framework-mapping/nist-csf-skill-mapping.md` | NIST CSF theme mapping across Govern, Identify, Protect, Detect, Respond, and Recover. |
| `framework-mapping/cobit-skill-mapping.md` | COBIT-aligned governance and management objective themes. |
| `framework-mapping/ai-governance-skill-mapping.md` | AI governance themes, approval gates, risk questions, and supporting skills. |

## How to Read the Mapping

Each mapping file uses themes rather than strict compliance claims.

For example, a skill may support a SOC 2 change management control by helping prepare evidence, but the exact control language, criteria, and evidence requirements depend on the organization's control environment and auditor expectations.

## Recommended Use in a Portfolio

Use the mappings to explain that this project demonstrates:

1. Practical GRC workflow design.
2. Control thinking beyond static documentation.
3. Audit evidence awareness.
4. Risk and exception management.
5. Change and incident governance.
6. AI and vendor risk governance.
7. Executive reporting and metrics.

## Recommended Use in Interviews

A strong interview explanation:

> I built this project to show how governance can be operationalized into repeatable workflows. Each skill supports a real GRC activity, such as reviewing change requests, preparing audit evidence, analyzing RCAs, building risk register entries, reviewing vendors, and evaluating AI tool intake. I also mapped the skills to ISO 27001, SOC 2, NIST CSF, and COBIT themes to show how practical workflows connect back to broader control frameworks.

## Recommended Use in GRC Training

For new GRC practitioners, the mappings can be used to show:

- How frameworks translate into daily work.
- How audit evidence supports control operation.
- How risk register entries connect to incidents and findings.
- How CAB review supports change governance.
- How vendor and AI reviews support third-party risk management.

## Important Disclaimer

These mappings are not certification evidence, legal advice, audit advice, or a formal control assessment. They are educational and practical workflow mappings that should be tailored to each organization's policies, control environment, risk profile, and auditor expectations.
