# Interactive Demo Site Guide

This guide explains the interactive GitHub Pages site added for the Governance Systems Skills Library.

## Purpose

The interactive site helps visitors understand the project quickly without reading every folder in the repository.

It highlights:

- The Governance Systems Engineering model
- The 11 Claude-compatible GRC skills
- Tested output examples
- Framework mapping
- Demo pathways
- Release download access
- Hiring manager and recruiter-friendly project positioning

## Main Site Sections

1. Hero section
2. Searchable skill library
3. Tested outputs overview
4. Framework mapping summary
5. Demo pathways
6. Portfolio call-to-action

## Maintenance Notes

When adding new skills:

1. Add the skill folder under `skills/`.
2. Add a tested output example.
3. Update the skill list in `index.html` and `site/index.html`.
4. Update `skill-catalog.json` if applicable.
5. Rerun validation and packaging workflows.
