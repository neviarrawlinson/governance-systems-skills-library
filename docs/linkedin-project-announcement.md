# LinkedIn Project Announcement Draft

I just published a new Governance Systems Engineering portfolio project:

**Governance Systems Skills Library**

This project is a Claude-compatible GRC skill library designed to help practitioners produce structured, audit-ready outputs across common governance workflows.

It includes 11 practical GRC skills:

- Change Governance Review
- CAB Readiness Check
- RCA Governance Analysis
- Audit Evidence Request
- Risk Register Builder
- Executive GRC Summary
- Policy Exception Review
- Third-Party Risk Review
- Control Evidence Quality Check
- Governance Metrics Summary
- AI Governance Intake Review

What makes this different is that it is not just a framework reference library.

It focuses on operational governance workflows, including how changes are reviewed, how evidence is assessed, how risks are documented, how RCAs are evaluated, how vendor and AI intake requests are reviewed, and how governance updates are summarized for leadership.

The project includes:

- Claude-compatible skill folders
- Tested output examples for every skill
- GitHub Pages landing site
- Automated skill validation
- Automated package workflow
- Downloadable release assets
- Methodology and architecture documentation

The goal is to show what GRC looks like when controls move beyond static documentation and become repeatable, AI-assisted governance workflows.
