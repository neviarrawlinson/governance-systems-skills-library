# LinkedIn Announcement Draft

I just published the stable release of my Governance Systems Skills Library.

This project started as a way to explore how Governance, Risk, and Compliance work can move beyond static documentation and become repeatable, workflow-driven, AI-assisted systems.

The library now includes 11 Claude-compatible GRC skills covering:

- Change governance review
- CAB readiness
- RCA governance analysis
- Audit evidence requests
- Risk register building
- Executive GRC summaries
- Policy exception review
- Third-party risk review
- Control evidence quality checks
- Governance metrics summaries
- AI governance intake review

Each skill includes a tested output example based on realistic governance scenarios.

The project also includes framework mappings, GitHub Actions validation, packaged release assets, a live GitHub Pages site, screenshots, installation guidance, and portfolio documentation.

This is part of my broader work around Governance Systems Engineering, which focuses on turning governance expectations into repeatable systems, decision points, evidence requirements, and leadership-ready outputs.
