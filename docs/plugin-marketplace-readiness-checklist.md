# Plugin Marketplace Readiness Checklist

## Purpose

This checklist helps determine whether the Governance Systems Skills Library is ready to be positioned as a Claude Code plugin-ready project.

## Required Structure

- [ ] `.claude-plugin/plugin.json` exists.
- [ ] `skills/` folder exists.
- [ ] Each skill includes `SKILL.md`.
- [ ] `commands/` folder exists.
- [ ] `agents/` folder exists.
- [ ] Plugin documentation exists.
- [ ] README explains plugin support.
- [ ] Live site explains plugin support.

## Documentation Readiness

- [ ] Plugin installation guide exists.
- [ ] Plugin component map exists.
- [ ] Plugin testing guide exists.
- [ ] Command guide exists.
- [ ] Agent guide exists.
- [ ] Team adoption guide exists.

## Validation Readiness

- [ ] Skill validation workflow passes.
- [ ] Plugin validation workflow passes.
- [ ] Package workflow passes.
- [ ] Release artifact is generated.
- [ ] README links are current.
- [ ] Live site links are current.

## Marketplace Positioning Notes

Do not claim official marketplace availability unless the project has been configured and tested for marketplace installation.

Recommended wording:

> Claude Code plugin-ready governance toolkit.

Avoid wording such as:

> Official Claude Code marketplace plugin.

unless marketplace publication has been completed.
