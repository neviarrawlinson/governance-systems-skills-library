# Project Positioning

## Project identity

Governance Systems Skills Library is a practical skill library for Governance Systems Engineering.

The project focuses on turning governance expectations into repeatable, reviewable, and audit-ready workflows.

## Differentiation

This is not a generic GRC framework library. It focuses on operational governance work:

- Reviewing change requests.
- Preparing CAB decisions.
- Analyzing RCAs.
- Checking audit evidence quality.
- Evaluating policy exceptions.
- Reviewing third-party risk.
- Summarizing governance metrics.
- Reviewing AI intake requests.

## Target users

- GRC analysts.
- IT governance analysts.
- Change managers.
- Audit coordinators.
- Risk analysts.
- Compliance managers.
- Security governance teams.
- Technology leaders building repeatable governance workflows.

## Core message

Controls should not live only in policy documents. They should show up in tickets, approvals, evidence, reports, and decisions.
