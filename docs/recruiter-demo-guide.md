# Recruiter Demo Guide

This guide explains how to present the project quickly to a recruiter.

## 30-Second Explanation

The Governance Systems Skills Library is a Claude-compatible GRC skills project that turns governance, risk, compliance, audit evidence, change management, RCA, vendor risk, and AI governance workflows into repeatable, tested, and audit-ready outputs.

It demonstrates practical Governance Systems Engineering: building reusable systems that help teams make better governance decisions and produce stronger evidence.

## What to Emphasize

Recruiters usually need a quick understanding of relevance.

Emphasize:

- Practical GRC workflow design
- Change management and CAB readiness
- Audit evidence and control readiness
- RCA and corrective action governance
- Risk register documentation
- Vendor risk and AI governance
- GitHub Actions automation
- Portfolio-ready technical documentation

## Suggested Recruiter Message

This project demonstrates my ability to turn governance requirements into structured workflows, tested outputs, and audit-ready documentation. It includes 11 Claude-compatible GRC skills, tested examples for each skill, framework mappings, GitHub Actions validation, packaging workflows, and a live GitHub Pages site.
