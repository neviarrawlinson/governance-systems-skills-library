# Screenshot Capture Guide

Use this guide to capture clean screenshots for the Governance Systems Skills Library README, GitHub Pages site, portfolio, LinkedIn post, and project case study.

## Screenshot 1: Live Landing Page Hero

Capture the top of the live GitHub Pages site.

Recommended file name:

```text

```

- Shows the live site is deployed.

## Screenshot Quality Tips

Use browser zoom between 80 percent and 100 percent.

Keep screenshots clean:

- Hide personal bookmarks if needed.
- Avoid cutting off headings.
- Capture enough surrounding context.
- Use consistent browser width when possible.
- Save screenshots as `.png`.
