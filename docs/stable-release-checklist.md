# Stable Release Checklist

Use this checklist before publishing the `v1.0.0` stable release.

## Repository Readiness

- [ ] README loads correctly on the main repo page.
- [ ] Live GitHub Pages site loads correctly.
- [ ] Download link points to the latest release after publishing.
- [ ] All screenshots load correctly in the README.
- [ ] The `skills/` folder contains all 11 skill folders.
- [ ] Each skill has a `SKILL.md` file.
- [ ] Each skill has a README file.
- [ ] Each skill has a tested output example.
- [ ] Each tested output link works.
- [ ] Framework mapping links work.
- [ ] Getting Started links work.
- [ ] Methodology and architecture links work.

## Automation Readiness

- [ ] Validate Skills workflow passes.
- [ ] Package Skills workflow passes.
- [ ] New package artifact downloads correctly.
- [ ] Release asset is named `governance-systems-skill-packages.zip`.

## Release Readiness

- [ ] Draft release tag is `v1.0.0`.
- [ ] Release title is `v1.0.0 - Stable Governance Systems Skills Library Release`.
- [ ] Release notes are added.
- [ ] Package artifact is attached.
- [ ] README download section is updated after publishing.
- [ ] Final validation workflow is run after README update.

## Portfolio Readiness

- [ ] GitHub About section includes a clear description.
- [ ] GitHub About section includes the live site URL.
- [ ] Repo topics are added.
- [ ] Project case study summary is complete.
- [ ] LinkedIn or portfolio announcement is ready.
