# Team Adoption Guide

## Purpose

This guide explains how a governance, risk, compliance, audit, or IT operations team could adopt the Governance Systems Skills Library.

## Adoption Model

Teams can use the library in four ways:

1. Claude-compatible skill reference library.
2. Claude Code plugin-ready toolkit.
3. Governance workflow documentation library.
4. Training and portfolio demonstration resource.

## Recommended Team Use Cases

- Change request review.
- CAB readiness checks.
- RCA quality review.
- Audit evidence pre-submission checks.
- Vendor intake review.
- AI use case review.
- Policy exception review.
- Governance metrics reporting.
- Risk register drafting.

## Suggested Operating Model

| Role | Responsibility |
|---|---|
| Governance Owner | Maintains workflow standards and skill usage guidance. |
| Process Owner | Confirms skill outputs align to operational procedures. |
| Security Reviewer | Reviews outputs involving security approval or risk. |
| Compliance Reviewer | Reviews audit and compliance evidence outputs. |
| Business Owner | Confirms business impact and ownership details. |

## Adoption Steps

1. Review the README and live site.
2. Download the latest skill package.
3. Select one pilot workflow.
4. Test the skill against a recent realistic scenario.
5. Compare output to existing governance expectations.
6. Capture gaps or improvements.
7. Document approved usage boundaries.
8. Expand to additional workflows.

## Governance Guardrails

The skills should support, not replace:

- Management approval.
- Formal audit judgment.
- Legal or regulatory interpretation.
- Security approval.
- Risk acceptance authority.
- Business ownership.
