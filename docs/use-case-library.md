# Use Case Library

This document summarizes practical use cases for the Governance Systems Skills Library.

## Change Governance Use Cases

### Review a Production Change Request

Use `change-governance-review` when a production change needs review for implementation plan, validation, rollback, monitoring, approvals, risk, and audit readiness.

### Determine CAB Readiness

Use `cab-readiness-check` when deciding whether a change should proceed to CAB, be approved with conditions, be held, or be rejected.

### Review Emergency Change Justification

Use the change governance skills to determine whether an emergency change includes sufficient justification, approvals, rollback, validation, and follow-up evidence.

## RCA and Incident Governance Use Cases

### Evaluate RCA Quality

Use `rca-governance-analysis` to review whether an RCA explains root cause, timeline, monitoring gaps, ownership issues, corrective actions, and audit readiness.

### Identify Monitoring Failures

Use RCA analysis when an outage or incident was detected by users instead of monitoring tools.

### Convert RCA Findings Into Risk Entries

Use `risk-register-builder` after an RCA identifies repeat risk, process weakness, monitoring gap, or control failure.

## Audit Evidence Use Cases

### Translate Audit Requests Into Evidence Checklists

Use `audit-evidence-request` to convert broad audit asks into specific evidence items, owner questions, submission guidance, and quality checks.

### Review Evidence Before Submission

Use `control-evidence-quality-check` to assess whether evidence is complete, timestamped, traceable, accurate, and aligned to the control objective.

### Prepare Audit Cover Notes

Use evidence quality outputs to create a transparent submission note that explains known gaps and remediation actions.

## Risk Management Use Cases

### Create a Risk Register Entry

Use `risk-register-builder` to convert issues, incidents, audit findings, control gaps, or governance observations into structured risk entries.

### Track Residual Risk

Use risk register outputs to document inherent risk, existing controls, control gaps, treatment plan, residual risk, and review cadence.

## Policy Governance Use Cases

### Review Policy Exception Requests

Use `policy-exception-review` to evaluate whether an exception request has a valid business justification, risk rating, compensating controls, expiration date, and approval path.

### Determine Whether Risk Acceptance Is Needed

Use policy exception review when a request bypasses a required control or creates temporary noncompliance.

## Third-Party Risk Use Cases

### Review a SaaS Vendor Intake

Use `third-party-risk-review` to evaluate vendor risk, SOC 2 status, DPA needs, security questionnaire status, access model, integrations, and data export risk.

### Evaluate Production Integration Risk

Use third-party review when a vendor wants API access, SSO integration, production access, or data export capability.

## AI Governance Use Cases

### Review AI Tool Intake

Use `ai-governance-intake-review` to evaluate AI use cases for data usage, prompt retention, model training, transparency, human review, ownership, security, privacy, and legal review.

### Approve or Hold AI Pilots

Use AI intake review to determine whether the pilot can proceed with production data, synthetic data, or should be held pending review.

## Executive Reporting Use Cases

### Summarize Governance Activity

Use `governance-metrics-summary` to turn governance metrics into leadership-ready summaries with trends, exceptions, risks, and recommended actions.

### Brief Leadership on Governance Risk

Use `executive-grc-summary` when governance findings need to be summarized for IT leadership, executives, auditors, or risk committees.
