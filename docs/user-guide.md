# User Guide

This guide explains how different users can get value from the Governance Systems Skills Library.

## For GRC practitioners

Use the skills to produce structured first drafts for governance workflows, including:

- CAB reviews
- RCA reviews
- Audit evidence checklists
- Risk register entries
- Executive summaries
- Policy exception decisions
- Vendor intake reviews
- AI use case intake reviews

## For IT governance teams

Use the library as a reference model for repeatable governance workflows.

The skills can help standardize:

- Required review criteria
- Approval decision language
- Evidence expectations
- Escalation notes
- Leadership summaries
- Risk treatment language
- Audit readiness documentation

## For auditors

Use the examples to understand how governance evidence can be structured before submission.

The library emphasizes:

- Traceability
- Approval timing
- Testing evidence
- Validation evidence
- Monitoring evidence
- RCA linkage
- Risk register linkage
- Corrective action tracking

## For hiring managers and recruiters

This project demonstrates applied GRC engineering capability, including:

- Workflow design
- Governance automation thinking
- Documentation systems
- AI-assisted control evaluation
- GitHub project organization
- Validation workflows
- Release packaging
- Portfolio presentation

## For learners

Use the tested outputs as examples of how to think like a GRC practitioner.

Each tested output shows:

- What information matters
- What gaps to look for
- How to explain risk
- How to write governance notes
- How to recommend next actions
