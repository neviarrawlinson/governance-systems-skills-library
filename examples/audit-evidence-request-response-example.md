# Audit Evidence Request Response Example

## Auditor Request

Please provide evidence that production changes were reviewed and approved before implementation during the audit period.

## Evidence Response Plan

### Evidence Needed

| Evidence | Purpose |
|---|---|
| Change ticket export for audit period | Shows population of production changes. |
| Sample change tickets | Shows approval, testing, rollback, and implementation details. |
| CAB approval records | Shows governance review occurred before implementation. |
| Implementation evidence | Shows when the change was completed. |
| Validation evidence | Shows post-change testing or confirmation. |

### Owner Questions

1. Which Jira project contains the authoritative production change records?
2. What field identifies production environment changes?
3. Where are CAB approvals recorded?
4. Are emergency approvals recorded differently from normal changes?
5. Are validation notes required before closure?

## Draft Submission Note

Attached is evidence supporting production change review and approval during the audit period. Evidence includes the production change population, selected change records, approval history, implementation details, and validation notes.

## Quality Checks Before Submission

- Confirm audit period is correct.
- Confirm sample tickets match the auditor-selected population.
- Confirm approvals occurred before implementation when required.
- Confirm screenshots or exports show ticket ID, status, dates, and approvers.
- Confirm any exceptions are documented and explained.
