# Before and After Change Review Example

## Before

The change request says:

"Updating production config. Testing after. Rollback if needed."

## Governance Concern

This is not audit-ready because it does not identify implementation steps, validation method, rollback criteria, monitoring approach, owner, risk, impact, or approvals.

## After

A stronger change request should include:

- A clear business reason
- Step-by-step implementation instructions
- Specific validation steps and success criteria
- A rollback plan with trigger conditions
- Risk and impact statement
- Monitoring plan
- Required approvals
- Post-implementation evidence
