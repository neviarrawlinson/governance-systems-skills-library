# Claude Code Demo: AI Governance Intake

## Scenario

A team requests approval to use a third-party AI assistant with internal reporting data and CSV uploads.

## Prompt

```text
Use the review-ai-intake command to review this AI intake request.

Use Case: AI Reporting Assistant
Purpose: Summarize reporting trends and draft leadership updates.
Data: Internal reporting data, employee IDs, operational dashboards, CSV exports.
Vendor Status: No SOC 2, no DPA, no AI-specific terms reviewed.
Integration: May connect to Reporting Service API.
Requested Decision: Approve pilot within two weeks.
```

## Expected Outcome

The command should recommend holding production or live-data approval.
