# End-to-End Demo: Audit Evidence Workflow

## Scenario

An auditor requests evidence that a sampled production change followed the change management process. The evidence package includes screenshots and notes, but several items are weak or missing.

## Workflow

### Step 1: Translate the Audit Request

Skill:

`audit-evidence-request`

Output:

- Evidence checklist
- Owner questions
- Evidence quality expectations
- Submission guidance

### Step 2: Check Evidence Quality

Skill:

`control-evidence-quality-check`

Output:

- Evidence quality assessment
- Gaps and weaknesses
- Traceability concerns
- Auditor concerns
- Remediation checklist

### Step 3: Convert Evidence Gaps Into Risk

Skill:

`risk-register-builder`

Output:

- Risk register entry
- Control gap documentation
- Corrective actions
- Evidence expectations

### Step 4: Summarize for Leadership

Skill:

`executive-grc-summary`

Output:

- Audit readiness summary
- Risk posture
- Required decisions
- Next actions

## Value

This workflow helps turn audit requests into a structured evidence process instead of a last-minute screenshot collection exercise.
