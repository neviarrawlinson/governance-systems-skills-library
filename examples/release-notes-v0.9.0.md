# v0.9.0 - Governance Framework Mapping Expansion

## Summary

This release adds framework mapping documentation that connects the Governance Systems Skills Library to common GRC, audit, risk, and governance frameworks.

## Added

- Skill to Framework Matrix
- ISO 27001 skill mapping
- SOC 2 skill mapping
- NIST CSF skill mapping
- COBIT skill mapping
- AI governance skill mapping
- Framework mapping guide
- Framework mapping coverage model
- Framework mapping review template
- README framework mapping snippet

## Why This Matters

This release strengthens the professional GRC credibility of the project by showing how workflow-based skills connect to recognized governance themes.

The project is not only a set of AI prompts or templates. It is a Governance Systems Engineering library that demonstrates how controls, risks, evidence, approvals, and reporting can be operationalized into repeatable workflows.

## Focus Areas

- Framework alignment
- Audit readiness
- Change governance
- RCA and incident governance
- Risk management
- Vendor risk
- AI governance
- Executive reporting
- Portfolio credibility

## Notes

The mappings are theme-based and should be adapted to each organization's policies, control environment, regulatory commitments, and auditor expectations.
