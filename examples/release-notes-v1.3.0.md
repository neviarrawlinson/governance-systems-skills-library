# v1.3.0 - Interactive Demo Site Upgrade

## Governance Systems Skills Library v1.3.0

This release upgrades the GitHub Pages site into a more interactive project demo experience.

## Added

- Interactive GitHub Pages landing page
- Skill cards with direct links to skill folders, SKILL.md files, and tested outputs
- Searchable skill library
- Category filters for skill navigation
- Framework mapping section on the site
- Demo pathway section
- Portfolio project summary call-to-action
- Site content map
- Interactive site guide
- Site upgrade checklist
- README interactive site section snippet

## Why This Matters

This release makes the project easier to evaluate without requiring visitors to manually browse the repository. Recruiters, hiring managers, and GRC practitioners can quickly understand the library structure, workflow purpose, tested outputs, framework mappings, and demo pathways.

## Focus Areas

- Interactive site experience
- Skill discoverability
- Recruiter readability
- Hiring manager navigation
- Portfolio presentation
- GRC Engineering project demonstration
