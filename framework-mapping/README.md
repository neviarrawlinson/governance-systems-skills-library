# Framework Mapping

This folder connects the operational skills in this repository to common governance, risk, and compliance frameworks.

The purpose is not to reproduce framework text. The purpose is to show how practical workflow skills can support control objectives such as change governance, access review, evidence quality, incident review, risk management, and leadership reporting.

## Mapping Files

| File | Focus |
|---|---|
| `iso-27001-change-governance-map.md` | How change governance skills support ISO-aligned control expectations. |
| `soc-2-change-governance-map.md` | How change review and evidence workflows support SOC 2 control readiness. |
| `nist-csf-governance-map.md` | How the skills align to NIST CSF governance and risk outcomes. |
| `cobit-governance-map.md` | How Governance Systems Engineering supports IT governance and management objectives. |
