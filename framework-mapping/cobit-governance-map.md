# COBIT Governance Mapping

## Purpose

This mapping explains how Governance Systems Engineering supports practical IT governance and management activities that are commonly associated with COBIT-style governance programs.

## Skill Alignment

| Skill | Governance or Management Support |
|---|---|
| `executive-grc-summary` | Supports management reporting, transparency, and decision-making. |
| `risk-register-builder` | Supports risk identification, analysis, and treatment tracking. |
| `change-governance-review` | Supports controlled change enablement and operational stability. |
| `cab-readiness-check` | Supports governance decision gates before implementation. |
| `audit-evidence-request` | Supports control evidence collection and assurance readiness. |
| `rca-governance-analysis` | Supports problem management, issue remediation, and continual improvement. |

## Governance Systems Engineering Connection

COBIT-style programs often require repeatable decision rights, accountability, controls, monitoring, and reporting. This repository demonstrates how those expectations can be translated into reusable skill packs, examples, templates, and workflow guidance.

## Practical Use

Use this mapping to explain how AI-assisted skills can support mature IT governance practices by making review criteria and outputs more consistent.
