# COBIT Skill Mapping

This page maps the Governance Systems Skills Library to COBIT-aligned governance and management objectives. The mapping is intended to show how AI-assisted GRC workflows can support governance, risk, change, supplier, incident, and performance management activities.

## COBIT Alignment Summary

| Skill | COBIT-Aligned Objective Theme | Governance Value |
|---|---|---|
| `change-governance-review` | BAI06 Managed IT Changes, DSS01 Managed Operations | Reviews whether technology changes are controlled, approved, validated, and monitored. |
| `cab-readiness-check` | BAI06 Managed IT Changes | Supports CAB readiness and change authorization decisions. |
| `rca-governance-analysis` | DSS02 Managed Service Requests and Incidents, DSS03 Managed Problems | Reviews incident analysis, problem management, corrective actions, and monitoring gaps. |
| `audit-evidence-request` | MEA03 Managed Compliance With External Requirements | Converts audit requests into evidence plans and owner questions. |
| `risk-register-builder` | APO12 Managed Risk, EDM03 Ensured Risk Optimization | Converts issues and findings into structured risk entries and treatment plans. |
| `executive-grc-summary` | EDM01 Governance Framework, EDM03 Risk Optimization | Supports leadership oversight and decision-making. |
| `policy-exception-review` | APO12 Managed Risk, MEA02 Managed System of Internal Control | Reviews exceptions, compensating controls, approvals, and risk acceptance. |
| `third-party-risk-review` | APO10 Managed Vendors, APO12 Managed Risk | Reviews vendor security, privacy, access, integration, and data processing risk. |
| `control-evidence-quality-check` | MEA01 Managed Performance and Conformance Monitoring, MEA03 Managed Compliance | Reviews whether evidence supports control operation and audit readiness. |
| `governance-metrics-summary` | MEA01 Managed Performance and Conformance Monitoring, EDM05 Stakeholder Engagement | Summarizes metrics, exceptions, trends, and leadership actions. |
| `ai-governance-intake-review` | APO12 Managed Risk, APO14 Managed Data, BAI03 Managed Solutions Identification and Build | Reviews AI use cases for data, vendor, model, access, and approval risks. |

## COBIT Workflow Themes

### Managed IT Changes

Relevant skills:

- `change-governance-review`
- `cab-readiness-check`
- `audit-evidence-request`
- `control-evidence-quality-check`

These skills support the governance and management of IT changes by checking readiness, approvals, validation, rollback, monitoring, and evidence quality.

### Managed Risk

Relevant skills:

- `risk-register-builder`
- `policy-exception-review`
- `third-party-risk-review`
- `ai-governance-intake-review`

These skills support risk identification, treatment, ownership, compensating controls, risk acceptance, and residual risk tracking.

### Managed Incidents and Problems

Relevant skills:

- `rca-governance-analysis`
- `risk-register-builder`
- `executive-grc-summary`

These skills support incident learning, problem identification, corrective action ownership, and leadership visibility.

### Managed Vendors

Relevant skills:

- `third-party-risk-review`
- `ai-governance-intake-review`
- `control-evidence-quality-check`

These skills support vendor due diligence, SaaS risk review, AI tool intake, data processing review, and evidence collection.

### Managed Performance and Conformance

Relevant skills:

- `governance-metrics-summary`
- `control-evidence-quality-check`
- `executive-grc-summary`

These skills support metrics, control monitoring, performance reporting, audit readiness, and management review.

## Practical COBIT Use Cases

| Governance Need | Recommended Skills |
|---|---|
| Review a production change | `change-governance-review`, `cab-readiness-check` |
| Determine if evidence supports a control | `control-evidence-quality-check` |
| Track a control gap as risk | `risk-register-builder` |
| Review vendor readiness | `third-party-risk-review` |
| Review AI use case approval readiness | `ai-governance-intake-review` |
| Prepare leadership reporting | `governance-metrics-summary`, `executive-grc-summary` |
| Review policy exception | `policy-exception-review` |
| Improve RCA quality | `rca-governance-analysis` |

## Usage Note

This mapping is designed for governance education and portfolio demonstration. Organizations should adapt the mapping to their own COBIT implementation, governance model, and control environment.
