# ISO 27001 Change Governance Mapping

## Purpose

This mapping shows how the skill packs can support ISO-aligned governance activities related to change control, operational control, incident learning, risk treatment, and documented evidence.

## Workflow to Control Support

| Skill | Governance Support |
|---|---|
| `change-governance-review` | Helps verify that production changes include implementation, validation, rollback, monitoring, and approvals. |
| `cab-readiness-check` | Supports consistent approval readiness before changes are implemented. |
| `rca-governance-analysis` | Supports review of incidents, root cause quality, corrective actions, and continual improvement. |
| `audit-evidence-request` | Helps collect evidence that demonstrates controls were performed. |
| `risk-register-builder` | Converts control gaps and repeated issues into risk records. |
| `executive-grc-summary` | Supports governance reporting and management visibility. |

## Example Evidence Artifacts

- Change request record with approvals.
- CAB meeting notes or approval history.
- Implementation and validation notes.
- Rollback plan and monitoring plan.
- RCA report with corrective actions.
- Risk register entry for repeated control gaps.
- Evidence collection checklist.

## Practical Use

Use this mapping to explain how workflow-based AI skills can support audit-ready governance operations without replacing the organization's official ISO control framework or auditor guidance.
