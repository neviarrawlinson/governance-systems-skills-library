# NIST CSF Governance Mapping

## Purpose

This mapping connects the project to NIST Cybersecurity Framework style outcomes such as governance, risk management, asset understanding, incident response, and improvement.

## Skill Alignment

| Skill | Governance Outcome Supported |
|---|---|
| `risk-register-builder` | Helps identify, document, and prioritize risk. |
| `change-governance-review` | Supports controlled technology change and risk-aware implementation. |
| `cab-readiness-check` | Supports decision quality before changes are approved. |
| `rca-governance-analysis` | Supports learning from incidents and improving detection and response. |
| `audit-evidence-request` | Supports evidence collection and accountability. |
| `executive-grc-summary` | Supports communication of risk and governance posture to leadership. |

## Example Governance Metrics

- Number of changes reviewed.
- Number of changes returned for missing controls.
- Emergency change volume.
- RCA corrective actions opened and closed.
- Audit evidence requests completed on time.
- High-risk items added to the risk register.

## Practical Use

Use this mapping to frame the skills as operational support for cyber governance outcomes, not as a replacement for formal framework implementation.
