# SOC 2 Skill Mapping

This page maps the Governance Systems Skills Library to SOC 2-relevant governance and evidence themes. The mapping is theme-based and should be adapted to the organization's actual controls, Trust Services Criteria, system description, and auditor requests.

## SOC 2 Alignment Summary

| Skill | SOC 2-Relevant Theme | Governance Value |
|---|---|---|
| `change-governance-review` | Change management and system operations | Checks whether changes include approval, testing, rollback, monitoring, and evidence. |
| `cab-readiness-check` | Change approval and pre-deployment governance | Helps determine whether changes are ready for approval or require conditions. |
| `rca-governance-analysis` | Incident response, corrective action, monitoring gaps | Reviews incident documentation, root cause depth, and remediation tracking. |
| `audit-evidence-request` | Evidence collection and audit response | Converts auditor requests into evidence checklists and submission notes. |
| `risk-register-builder` | Risk assessment and mitigation tracking | Converts gaps into risk entries with treatment plans and residual risk. |
| `executive-grc-summary` | Management communication and oversight | Summarizes risks, findings, actions, and governance concerns for leadership. |
| `policy-exception-review` | Exception documentation and risk acceptance | Reviews whether exceptions are approved, time-bound, controlled, and evidenced. |
| `third-party-risk-review` | Vendor management, confidentiality, privacy | Reviews SOC reports, DPA, data flow, access, and third-party risk evidence. |
| `control-evidence-quality-check` | Control evidence quality | Assesses whether evidence is complete, traceable, timely, and relevant. |
| `governance-metrics-summary` | Control monitoring and management review | Turns governance metrics into leadership-ready trends and action items. |
| `ai-governance-intake-review` | AI vendor risk, data processing, confidentiality, privacy | Reviews AI tool intake for data use, vendor due diligence, prompt retention, and approvals. |

## SOC 2 Evidence Themes

### Change Management Evidence

Relevant skills:

- `change-governance-review`
- `cab-readiness-check`
- `audit-evidence-request`
- `control-evidence-quality-check`

Example evidence supported:

- Change ticket
- Approval record
- Testing evidence
- Validation evidence
- Rollback plan
- Post-deployment monitoring evidence
- CAB decision notes
- Exception note, if applicable

### Incident and Corrective Action Evidence

Relevant skills:

- `rca-governance-analysis`
- `risk-register-builder`
- `executive-grc-summary`

Example evidence supported:

- Incident record
- RCA document
- Root cause analysis
- Corrective action tickets
- Monitoring gap analysis
- Risk register entry
- Leadership summary

### Vendor and Data Protection Evidence

Relevant skills:

- `third-party-risk-review`
- `ai-governance-intake-review`
- `policy-exception-review`

Example evidence supported:

- Vendor risk review
- SOC 2 report request
- DPA review questions
- Security questionnaire
- Data flow diagram
- Access control review
- Exception approval record

### Governance Monitoring Evidence

Relevant skills:

- `governance-metrics-summary`
- `executive-grc-summary`
- `control-evidence-quality-check`

Example evidence supported:

- Metrics report
- Control gap trend analysis
- Overdue corrective action report
- Audit evidence readiness summary
- Leadership decision log
