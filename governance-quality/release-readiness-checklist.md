# Release Readiness Checklist

Use this checklist before publishing a release.

- [ ] All skills pass validation.
- [ ] New skills are listed in `skills/README.md`.
- [ ] New skills are listed in `skill-catalog.json`.
- [ ] Sample input and sample output files exist for new skills.
- [ ] `CHANGELOG.md` is updated.
- [ ] `README.md` reflects the current skill count.
- [ ] `package-skills.sh` runs successfully.
- [ ] `dist/` contains current packaged skill zip files.
- [ ] GitHub Pages landing page is updated.
