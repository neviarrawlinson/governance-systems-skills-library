# Skill Review Rubric

Score each skill from 1 to 5 in each category.

| Category | 1 | 3 | 5 |
|---|---|---|---|
| Practicality | Generic advice | Useful but uneven | Directly usable in practitioner workflow |
| Governance depth | Surface-level | Identifies some gaps | Identifies control, risk, evidence, and approval gaps |
| Output consistency | Unstructured | Mostly structured | Always follows required format |
| Audit readiness | Not audit-aware | Some audit awareness | Produces defensible, evidence-aware output |
| Clarity | Confusing | Understandable | Clear, concise, decision-ready |

## Passing threshold

A publishable skill should average at least 4.0 and have no category below 3.
