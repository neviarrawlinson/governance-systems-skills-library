# Skill Quality Checklist

Use this checklist before publishing or packaging any skill.

## Metadata

- [ ] Skill folder name uses lowercase letters and hyphens.
- [ ] `SKILL.md` exists.
- [ ] YAML frontmatter includes `name`.
- [ ] YAML frontmatter includes `description`.
- [ ] Name matches the folder name.
- [ ] Description clearly explains when to use the skill.

## Content

- [ ] Purpose is clear.
- [ ] Review criteria are practical and workflow-based.
- [ ] Output format is specific and reusable.
- [ ] Skill does not rely on unsupported legal, regulatory, or audit claims.
- [ ] Skill includes guidance not to invent facts.

## Examples

- [ ] Sample input exists.
- [ ] Sample output exists.
- [ ] Sample output follows the required format.
- [ ] Sample output includes findings and next actions.

## Governance value

- [ ] Skill helps identify risk, control, approval, evidence, or accountability gaps.
- [ ] Skill produces a decision-ready output.
- [ ] Output could be used in Jira, Confluence, an audit file, or an executive update.
