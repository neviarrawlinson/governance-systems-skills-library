# Project Demo Script

Use this script to walk through the project in a portfolio review or interview.

## 30-Second Demo

This is my Governance Systems Skills Library. It is a Claude-compatible GRC skills library focused on Governance Systems Engineering. It includes 11 reusable skills for change governance, RCA, audit evidence, risk, vendor risk, policy exceptions, governance metrics, and AI governance. Each skill has a tested output example, framework mapping, and supporting documentation. The project also includes GitHub Actions validation, automated packaging, a GitHub Pages site, and downloadable release assets.

## 2-Minute Demo Flow

1. Start with the live GitHub Pages site.
2. Show the README project preview screenshots.
3. Open the skills folder and show the 11 skills.
4. Open one skill, such as `change-governance-review`.
5. Show the tested output example.
6. Open the framework mapping section.
7. Show the GitHub Actions validation workflow.
8. Show the latest release and downloadable package.
9. Explain how the project demonstrates Governance Systems Engineering.

## Closing Statement

The main value of this project is that it shows how GRC expectations can be translated into operational workflows, tested outputs, evidence requirements, and repeatable governance systems.
