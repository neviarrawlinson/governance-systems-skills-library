# Governance Systems Skills Library

## Project Overview

The Governance Systems Skills Library is a Claude-compatible GRC skill library designed to demonstrate Governance Systems Engineering in practice.

It converts common governance, risk, compliance, audit, and AI governance workflows into reusable skill packs with tested outputs, framework mappings, and automated validation.

## Problem

Many governance programs rely on static documentation, but daily GRC work happens in operational workflows such as tickets, CAB reviews, RCA documents, audit evidence packages, vendor intake requests, risk registers, and leadership summaries.

This creates a gap between what the governance process says and what actually happens.

## Solution

This project turns governance expectations into repeatable skill-based workflows that can help practitioners produce more consistent, audit-ready outputs.

## Key Features

- 11 Claude-compatible GRC skills
- Tested output examples for every skill
- Framework mapping to ISO 27001, SOC 2, NIST CSF, COBIT, and AI governance themes
- GitHub Actions validation workflow
- Automated skill packaging workflow
- GitHub Pages live site
- Downloadable packaged release assets
- Installation and troubleshooting documentation

## Skills Demonstrated

- GRC workflow design
- Change management governance
- RCA and corrective action analysis
- Audit evidence readiness
- Risk documentation
- Third-party risk review
- AI governance intake review
- Framework mapping
- GitHub documentation and release management
- Automation with GitHub Actions
