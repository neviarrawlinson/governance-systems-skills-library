# Resume Project Bullets

Use these bullets to describe the project on a resume, portfolio, or job application.

## Project Title

Governance Systems Skills Library

## One-Line Description

Built a Claude-compatible GRC skills library that converts governance, audit, risk, vendor, and AI governance workflows into reusable skill packs with tested outputs, framework mappings, and automated release packaging.

## Resume Bullets

- Designed and built a Claude-compatible Governance Systems Skills Library with 11 reusable GRC skills covering change governance, CAB readiness, RCA analysis, audit evidence, risk registers, vendor risk, policy exceptions, governance metrics, and AI intake review.
- Created tested output examples for every skill to demonstrate realistic governance scenarios, audit-ready structure, and repeatable practitioner workflows.
- Mapped skills to ISO 27001, SOC 2, NIST CSF, COBIT, and AI governance themes to show practical control alignment and audit relevance.
- Implemented GitHub Actions workflows to validate skill structure and package downloadable skill bundles for release management.
- Published a GitHub Pages site, release artifacts, screenshots, documentation, quickstart guides, and troubleshooting resources to support practitioner adoption and portfolio demonstration.

## Interview Framing

This project shows that I can take GRC requirements and operationalize them into structured workflows, reusable templates, automated checks, tested examples, and leadership-ready outputs. It bridges traditional GRC documentation with practical governance engineering and AI-assisted workflow design.
