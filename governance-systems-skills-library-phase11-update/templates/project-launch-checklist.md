# Project Launch Checklist

Use this checklist before publicly promoting the project.

## GitHub Repo

- [ ] README is current.
- [ ] Release link points to the latest version.
- [ ] Screenshots load correctly.
- [ ] GitHub Pages site works.
- [ ] About section is filled out.
- [ ] Topics are added.
- [ ] Latest release has downloadable asset.
- [ ] Validation workflow passes.
- [ ] Package workflow passes.

## Portfolio

- [ ] Project added to portfolio site.
- [ ] GitHub profile README updated.
- [ ] Resume project bullets added.
- [ ] Case study written or linked.

## Public Launch

- [ ] LinkedIn post drafted.
- [ ] Hashnode or Medium article drafted.
- [ ] Community post prepared.
- [ ] Demo script ready.
- [ ] Screenshots available.

## Interview Readiness

- [ ] 30-second project explanation ready.
- [ ] 2-minute demo script ready.
- [ ] Framework mapping explanation ready.
- [ ] Governance Systems Engineering explanation ready.
