What This Project Does

This library turns GRC workflows into repeatable AI-assisted skills. It is designed for practitioners who need to review change requests, prepare CAB summaries, analyze RCAs, respond to audit evidence requests, structure risks, and brief leadership.

Initial Skill Packs

Change Governance Review

Reviews change requests for implementation, validation, rollback, risk, monitoring, approvals, and audit readiness.

CAB Readiness Check

Determines whether a change is ready for CAB and identifies blockers before approval.

RCA Governance Analysis

Reviews RCA documentation for root cause quality, monitoring gaps, ownership, and corrective actions.

Audit Evidence Request

Converts vague audit requests into clear evidence checklists, owner questions, and submission notes.

Risk Register Builder

Converts issues, incidents, findings, and gaps into structured risk register entries.

Executive GRC Summary

Creates concise leadership-ready summaries for governance, audit, compliance, risk, and change updates.

Practitioner Workflow

  1. Use change-governance-review to evaluate a change request.
  2. Use cab-readiness-check to decide whether the change is ready for CAB.
  3. Use risk-register-builder when repeatable gaps become risks.
  4. Use rca-governance-analysis when an incident or failed change requires review.
  5. Use audit-evidence-request when evidence must be collected.
  6. Use executive-grc-summary to report outcomes to leadership.

Framework Mapping

The library includes practical mapping references for ISO 27001, SOC 2, NIST CSF, and COBIT. These mappings show how workflow-based skills can support control execution, evidence quality, risk tracking, and management reporting.
