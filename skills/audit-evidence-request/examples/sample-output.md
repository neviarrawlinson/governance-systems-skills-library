## Evidence Checklist

| Evidence Item | Purpose | Owner Question |
|---|---|---|
| AWS user access listing from audit period | Shows population reviewed. | Who exported the access listing and when? |

| Exception/remediation tickets | Shows inappropriate access was tracked. | Were any users removed or modified? |
| Removal confirmation screenshots or logs | Shows timely remediation. | What date was access removed? |

## Quality Checks

- Evidence should show system name, date, reviewer, and user population.
- Screenshots should include visible date/time when possible.
- Access removals should be tied to ticket numbers or documented approvals.
- Any exceptions should have owner, due date, and closure evidence.
