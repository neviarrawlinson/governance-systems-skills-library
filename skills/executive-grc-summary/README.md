# Executive GRC Summary

## Purpose

Creates concise leadership-ready summaries for governance, audit, compliance, risk, RCA, and change management updates.

## When to Use

Use this skill when you need a structured, repeatable governance output instead of an informal review. It is designed for practical GRC work where decisions, evidence, and follow-up actions need to be clear.

## Best Inputs

Provide as much context as possible, including:

- System, process, application, or environment involved.
- Business reason or operational context.
- Known risks, gaps, approvals, owners, or deadlines.
- Current draft documentation, if available.
- Required output format, audience, or decision point.

## Expected Outputs

This skill should produce:

- A clear summary of the issue or request.
- Governance findings.
- Gaps or blockers.
- Required corrections or recommended next actions.
- A polished note or artifact that can be reused in Jira, Confluence, audit workpapers, or leadership communications.
