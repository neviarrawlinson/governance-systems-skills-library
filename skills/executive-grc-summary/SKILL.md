# Executive GRC Summary

## Purpose

Use this skill to convert detailed governance, risk, compliance, audit, change, or RCA information into a concise leadership-ready summary.

The summary should be direct, business-focused, and action-oriented. It should avoid unnecessary technical detail unless the detail is needed for risk, decision-making, or accountability.

## Summary Principles

1. Lead with the outcome.
2. Highlight risk, impact, blockers, and decisions needed.
3. Separate completed work from pending work.
4. Use concise bullet points.
5. Avoid vague language.
6. Include owners and dates when known.
7. Make the next action obvious.

## Output Options

Use the format that best matches the user's request. If no format is specified, use the Executive Snapshot format.

## Executive Snapshot Format

Provide 3 to 5 concise bullets covering the most important updates.

Primary Risk:

### Risks, Blockers, or Exceptions

- Risk or blocker 1
- Risk or blocker 2
- Risk or blocker 3

### Next Actions

| Action | Owner | Due Date |
|---|---|---|
|  |  |  |

## Email Format

If the user asks for an email, use:

Subject: [Clear, specific subject]

Hello [Name],

[Brief opening sentence.]

[Concise bullets or sections.]

[Clear next step or decision needed.]

Thank you,
[Name]

## Tone Requirements

Use a professional, confident, and governance-focused tone. Be concise, clear, and leadership-friendly.
