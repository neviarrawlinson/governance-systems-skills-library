# Governance Metrics Summary

## What this skill does

Use this skill to convert raw governance data into a concise executive-ready summary that supports decisions, accountability, and process improvement.

## Use this skill when you need to

- Review whether a request is governance-ready.
- Identify missing evidence, approvals, owners, or controls.
- Produce concise governance notes for Jira, Confluence, or audit records.
- Create decision-ready summaries for risk, compliance, security, legal, or leadership reviewers.

## Main output

Executive snapshot, metric table, trend observations, risk/exception callouts, and recommended actions.

## Files

- `SKILL.md`: Claude-compatible skill instructions.
- `examples/sample-input.md`: Example request or dataset.
- `examples/sample-output.md`: Example skill output.
- `references/checklist.md`: Supporting review checklist.
