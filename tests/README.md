# Governance Skills Evaluation Framework

This folder contains structured evaluation assets for the Governance Systems Skills Library.

The purpose of this test layer is to show that the skills are not only documented, but can also be evaluated against expected governance outcomes.

## Evaluation Goals

The evaluation framework checks whether skill outputs:

- Identify material governance gaps.
- Recommend an appropriate decision or status.
- Explain risk in business and control terms.
- Identify missing evidence, owners, approvals, and due dates.
- Produce output that is usable for audit, CAB, risk, or leadership review.
- Maintain a clear, professional, governance-oriented tone.

## Evaluation Model

Each skill can be evaluated using a 100-point scorecard:

| Category | Points |
|---|---:|
| Correct decision or recommendation | 20 |
| Governance gap identification | 20 |
| Risk and impact analysis | 15 |
| Evidence and traceability requirements | 15 |
| Ownership and accountability | 10 |
| Output usability | 10 |
| Tone and professional judgment | 10 |

A score of 85 or higher is considered portfolio-ready.
