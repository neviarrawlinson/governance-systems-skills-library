# Governance Skill Evaluation Scorecard

Use this scorecard to evaluate outputs generated by the Governance Systems Skills Library.

| Evaluation Area | Max Points | Score | Notes |
|---|---:|---:|---|
| Correct decision or recommendation | 20 |  | Did the skill recommend the right status, such as approve, hold, reject, not audit-ready, or ready with conditions? |
| Governance gap identification | 20 |  | Did the skill identify the most important governance, approval, evidence, validation, rollback, monitoring, or ownership gaps? |
| Risk and impact analysis | 15 |  | Did the skill explain operational, audit, compliance, security, privacy, or business impact? |
| Evidence and traceability requirements | 15 |  | Did the skill identify required artifacts, approvals, timestamps, owners, records, and linkage needs? |
| Ownership and accountability | 10 |  | Did the skill identify named owner needs, due dates, escalation paths, or accountability gaps? |
| Output usability | 10 |  | Is the output usable as a Jira note, CAB summary, audit response, risk entry, executive summary, or governance record? |
| Tone and professional judgment | 10 |  | Is the output concise, professional, objective, and appropriate for GRC stakeholders? |
| **Total** | **100** |  |  |

## Result Rating

| Total Score | Result |
|---:|---|
| 90-100 | Excellent |
| 80-89 | Strong |
| 70-79 | Needs Improvement |
| Below 70 | Not Ready |
