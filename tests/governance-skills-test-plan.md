# Governance Skills Test Plan

## Purpose

This test plan defines how to evaluate the Governance Systems Skills Library against realistic GRC scenarios.

The goal is to demonstrate that each skill can produce structured, practical, audit-aware governance outputs.

## Scope

This test plan covers the following skills:

- `change-governance-review`
- `cab-readiness-check`
- `rca-governance-analysis`
- `audit-evidence-request`
- `risk-register-builder`
- `executive-grc-summary`
- `policy-exception-review`
- `third-party-risk-review`
- `control-evidence-quality-check`
- `governance-metrics-summary`
- `ai-governance-intake-review`

## Evaluation Approach

Each test case should include:

1. Scenario context.
2. Input prompt.
3. Expected decision or recommendation.
4. Expected governance gaps.
5. Expected evidence requirements.
6. Expected risk or audit concerns.
7. Scoring notes.

## Scoring Thresholds

| Score Range | Rating | Interpretation |
|---|---|---|
| 90-100 | Excellent | Ready for portfolio demonstration. |
| 80-89 | Strong | Usable with minor refinement. |
| 70-79 | Needs Improvement | Output identifies some gaps but misses important governance issues. |
| Below 70 | Not Ready | Output is incomplete, generic, or not governance-ready. |

## Evaluation Runs

Use the evaluation scorecard and test log template to record results for each run.

Recommended evidence for each evaluation run:

- Prompt used.
- Skill selected.
- Output generated.
- Scorecard result.
- Reviewer notes.
- Improvement actions.
